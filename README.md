# מנגנון החיפוש של התוסף "אוצר החכמה, בר אילן והתקליטור התורני"

המאגר הזה משמש רק לעדכון אוטומטי של התוסף לאפליקציית קלוד. יש בו שני קבצים:

- `latest.ps1`: מנגנון החיפוש שהתוסף מריץ במחשב.
- `latest.json`: הגרסה, הגיבוב (sha256) והחתימה.

בכל הפעלה התוסף בודק כאן אם יש גרסה חדשה. הוא מתקין אותה רק אם החתימה נבדקת מול המפתח שבתוכו. התוסף לא שולח לכאן שום מידע.

החיפוש עצמו רץ כולו במחשב של המשתמש, בתוכנות שהוא רכש כחוק.
